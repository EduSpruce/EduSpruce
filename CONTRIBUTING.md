# Contribuir

Obrigado pelo interesse em melhorar o EduSpruce.

## Como está organizado
- A aplicação completa está em **`index.html`** (HTML, CSS e JavaScript, sem dependências externas nem passo de compilação).
- O código está dentro de uma única função; os módulos novos são acrescentados antes do marcador `const comPrazo=` e estendem as funções existentes por reatribuição.
- A interface é em **português europeu**, com os títulos dos botões em maiúsculas iniciais.

## Antes de propor uma alteração
1. Teste no **iPad (Safari)**, num computador e num telemóvel — o iPad é o dispositivo principal.
2. Verifique a sintaxe: extraia o `<script>` principal e corra `node --check`.
3. Experimente com **Definições › Ferramentas › Criar Demonstração**; nunca use dados reais de alunos em capturas de ecrã ou *issues*.
4. Atualize `docs/ESPECIFICACAO.md` e, se mudar o formato dos dados, `docs/FORMATO_DADOS.md`.

## Sugestões
Use os modelos de *issue* («Problema» ou «Sugestão») ou **Definições › Ferramentas › Enviar Sugestão ou Problema** na app.
